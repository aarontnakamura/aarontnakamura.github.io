# Aaron Nakamura — personal website

Personal academic website for Aaron Nakamura, hosted with GitHub Pages.

## Local preview

Open `index.html` directly, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publishing

This repository is designed to publish from the root of the `main` branch as a GitHub Pages user site.
